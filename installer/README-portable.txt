Konbini (portable)
==================

1. Extract this zip to a folder you can write to (for example Documents\Konbini or a USB drive).
   Don't run it from inside the zip.
2. Double-click Konbini.exe.

Nothing is installed and nothing is written to your user profile: settings and any components you
download later (extra AI models, the video engine) are kept in the "Konbini Data" folder next to
Konbini.exe. To remove Konbini, just delete the folder.

Requirements: Windows 10 or 11 (64-bit) with .NET Framework 4.8, which Windows already includes.
The AI tools use your graphics card when available and fall back to the processor.

Windows may show a "Windows protected your PC" (SmartScreen) message the first time, because this
build isn't code-signed. Click "More info", then "Run anyway".
